# Mainline 桌面客户端（Mainline-Desktop）

把「主线 · Mainline」打成一个可以让别人直接双击运行的 Windows 桌面客户端。
本文件夹是 `personal-desk` 的**独立副本**，所有修改只发生在这里，原文件夹未改动。

当前可直接下载的单文件版与升级步骤见 [Windows EXE 安装说明](Windows-EXE-安装.md)。桌面版还包含两级项目结构、具体项目进度、活动免进度，以及合并后的“长期成长”页面；完整功能见 [README](README.md)。

## 桌面化的基础改动

| 文件 | 改动 |
| --- | --- |
| `server.py` | EXE 模式从打包资源目录读取网页；用户数据默认存到 `%LOCALAPPDATA%\Mainline\data`，并支持两级项目与活动记录 |
| `desktop.py`（新增） | 桌面启动器：占用端口检测 → 后台线程启动 → 健康检查就绪 → pywebview 桌面窗口；**关闭窗口即安全停止后台**；无 pywebview 时退回浏览器 |
| `build.cmd` / `build-onefile.cmd`（新增） | 一键打包脚本（文件夹版 / 单文件版） |

## 快速打包

构建电脑需要 Python 3.11+（接收者不需要任何环境）：

```bat
cd Mainline-Desktop
build.cmd
```

产物是 `dist\Mainline\` 文件夹，内含 `Mainline.exe`。**分发整个文件夹**（可压缩成 zip 发给别人），对方解压后双击 `Mainline.exe` 即可，会弹出桌面窗口而不是浏览器。

想要"只有一个 EXE"：

```bat
build-onefile.cmd
```

产物是单个 `dist\Mainline.exe`。首次启动会慢一点（自解压）；数据仍在 `%LOCALAPPDATA%\Mainline\data`。

## 体积控制（已做）

- 独立 venv 构建，不把系统里无关的包带进 EXE
- 排除 `tkinter`、`unittest`、`tests`、Qt/GTK 等无用模块
- 后端只用 Python 标准库 + pypdf；前端是原生 HTML/JS，没有 Node 运行时
- 用 `--onedir` 而不是 `--onefile` 时启动更快、体积相同；单文件版只是便于分发

实测体积见 `release-体积说明.txt`（构建后生成）。预期约 25–40 MB（文件夹版），远小于带 Electron 的方案。

## 数据与隐私

- 任务、附件、备份、模型密钥配置都在使用者的 `%LOCALAPPDATA%\Mainline\data`
- 密钥不回显、不写入数据库/导出；没有模型配置时本地功能照常可用
- 服务只监听 `127.0.0.1`，网页不加载任何外部资源

## 冒烟测试

```powershell
# 源码方式快速验证（不需要打包）
$env:MAINLINE_DATA_DIR = "$env:TEMP\mainline-trial\data"
python desktop.py
```

打包版验证：双击 `dist\Mainline\Mainline.exe`，窗口出现后新建一条任务，关闭窗口重新打开，任务仍在即通过。

## 升级与卸载

- 升级：用新版 `Mainline.exe` 覆盖旧文件即可，数据不受影响（在 LOCALAPPDATA）
- 卸载：删除程序文件夹 + `%LOCALAPPDATA%\Mainline`
